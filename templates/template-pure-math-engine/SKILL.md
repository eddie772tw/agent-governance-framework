# 領域核心演算法與數學運算技能範本 (Pure Algorithm & Math Engine)

> [!NOTE]
> 本文件為範本技能。若專案包含複雜的計算公式或業務規則引擎，可將本範本複製至 `.agents/skills/<your-math-engine>/SKILL.md` 並客製化。

---

## 核心設計原則

1. **單一事實來源 (Single Source of Truth)**：所有核心計算公式、業務決策樹與驗證規則，必須統一收攏於專屬領域工具模組（例如 `src/utils/mathEngine.ts` 或 `backend/math_engine.py`），嚴禁散落於 UI 或 Controller。
2. **純函數無副作用 (Pure Functions)**：所有計算函數必須具備確定性，不得依賴全域狀態、外部 I/O 或時間亂數。
3. **單位與型別嚴格性**：所有輸入與輸出必須具備精確的型別標註與單位定義，避免在不同模組間傳遞未經轉換的原始數據。

---

## 單元測試規範

1. **邊界與極端值斷言**：測試案例必須涵蓋最小值、最大值、除以零防護、空輸入與極端偏差輸入。
2. **相對關係與單調性驗證**：若公式存在物理或業務相對關係（例如 A 增加時 B 必增加），應撰寫單調性斷言測試。
3. **無 DOM / 無 UI 依賴**：測試模組必須為純函數隔離測試，執行速度在毫秒級內。
